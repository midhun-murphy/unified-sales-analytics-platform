# Unified Sales Analytics Platform

## Business Problem

Atlikon, a sports equipment company, acquired SportBar, an energy drink and sports nutrition company. While Atlikon already had an established OLAP-based analytics platform and reporting ecosystem, SportBar's data existed in separate OLTP systems.

The goal of this project was to integrate SportBar's operational data into Atlikon's enterprise data warehouse and provide a unified analytics view across both businesses.

## Project Overview

Designed and implemented an end-to-end data engineering solution using Databricks, PySpark, SQL, and Power BI to ingest, transform, model, and analyze SportBar sales data before integrating it with Atlikon's existing analytics platform.

## Data Pipeline Architecture

### Incremental Data Ingestion

* Ingested SportBar transactional data using incremental loading techniques.
* Processed only newly added or modified records.
* Automated pipeline execution using Databricks workflows.
* Successfully validated incremental loads.
* Moved processed files to a dedicated Processed folder after successful ingestion to prevent duplicate processing.

### Bronze Layer (Raw Data)

Loaded raw source data into Bronze tables without transformation.

Source Tables:

* Customers
* Products
* Gross Price
* Orders

Bronze layer served as the system-of-record for all incoming SportBar data.

### Silver Layer (Cleaned Data)

Implemented PySpark transformations to:

* Remove duplicate records
* Handle missing values
* Standardize formats
* Apply business rules
* Validate data quality

Created curated datasets ready for analytics processing.

### Gold Layer (Business Model)

Designed a dimensional data model consisting of:

Dimension Tables:

* Dim_Customers
* Dim_Products
* Dim_Gross_Price

Fact Table:

* Fact_Orders

Implemented SQL and PySpark transformations to build fact and dimension tables following data warehouse best practices.

### Enterprise Data Consolidation

Atlikon already maintained Gold-layer analytical tables for its sports products business.

After creating the SportBar Fact and Dimension tables:

* Analyzed and transformed SportBar business data.
* Merged SportBar Gold-layer data into Atlikon's existing enterprise Gold layer.
* Unified both companies' data within a common analytical model.
* Enabled consolidated reporting across Sports Equipment and Energy Drink business units.

The final Gold layer provided a single source of truth containing data from both Atlikon and SportBar.

## Databricks SQL Warehouse

* Published consolidated Gold-layer tables to Databricks SQL Warehouse.
* Optimized data for reporting and analytical workloads.
* Enabled secure access for BI tools.

## Power BI Reporting

Connected Power BI to Databricks using:

* Server Hostname
* HTTP Path
* Personal Access Token

Created:

* Fact-to-Dimension relationships
* Star Schema data model
* Cross-company reporting dashboards

## Dashboard Insights

### Executive Overview

Provides a high-level view of business performance through key metrics:

* Total Revenue
* Total Quantity Sold
* Unique Customers
* Average Selling Price

### Product Performance Analysis

Analyzes revenue generated by individual products to identify best-selling and high-performing products.

Insights include:

* Total Revenue by Product
* Top Revenue Generating Products
* Product-wise Sales Contribution

### Channel Performance Analysis

Evaluates sales performance across different sales channels.

Insights include:

* Revenue by Channel
* Retailer vs Direct Sales Contribution
* Channel-wise Revenue Distribution

### Variant Performance Analysis

Measures the performance of product variants based on revenue generation.

Insights include:

* Revenue by Variant
* Top Performing Variants
* Variant-wise Sales Trends

### Sales Trend Analysis

Tracks revenue performance over time to identify growth patterns and seasonal trends.

Insights include:

* Monthly Revenue Trend
* Revenue Growth Analysis
* Peak Sales Period Identification

### Customer Revenue Analysis

Provides visibility into customer purchasing behavior and contribution to overall revenue.

Insights include:

* Customer-wise Revenue
* Quantity Sold by Customer
* Top Revenue-Contributing Customers

### Interactive Filtering

Users can dynamically analyze data using:

* Year Filter
* Quarter Filter
* Month Filter
* Sales Channel Filter
* Product Category Filter
